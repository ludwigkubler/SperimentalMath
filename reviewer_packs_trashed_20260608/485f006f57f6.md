**Field B** (complexity object): Goemans-Williamson / SOS-degree-2 (Delorme-Poljak) SDP integrality gap for unweighted Max-Cut on 3-regular graphs

**Statement**:

> For every connected 3-regular graph G on n vertices with adjacency matrix A, define the cut polynomial g_G(x) := x^T A x for x ∈ {±1}^n and the Bonami-Beckner kurtosis excess κ(G) := E_x[g_G(x)^4] / E_x[g_G(x)^2]^2 − 3, where E_x is uniform over {±1}^n. Then the Goemans-Williamson / SOS-2 integrality gap obeys (DP(G) − MaxCut(G)) / |E(G)| ≤ 0.5 · max(κ(G), 1/n)^{1/4}, where DP(G) = |E|/2 + n·|λ_min(A)|/4 is the Delorme-Poljak eigenvalue SDP bound. A single 3-regular G with n ≤ 20 violating this inequality falsifies the conjecture.

**Rationale (proposer's reasoning)**:

> Goemans-Williamson rounding succeeds exactly when the SDP-induced quadratic form g_G behaves Gaussianly under random ±1 inputs; the Bonami-Beckner (4,2)-hypercontractive excess kurtosis κ is the canonical degree-2 deviation-from-Gaussianity invariant and is therefore a natural Fourier-analytic certificate for SDP tightness. Since g_G is degree-2, its full Fourier mass sits at level ≤ 2, so κ measures purely the 4th-cumulant cross-edge structure that GW rounding fails to capture. If true, this gives a polynomial-time computable moment-matrix-style witness P(M) = κ that any 0.879-approximator must respect, transferable under polynomial reductions that preserve quadratic structure.

import random

from itertools import combinations

def gaussian_elimination(matrix):
    n = len(matrix)
    for i in range(n):
        # Find pivot
        max_row = i
        for k in range(i+1, n):
            if abs(matrix[k][i]) > abs(matrix[max_row][i]):
                max_row = k
        matrix[i], matrix[max_row] = matrix[max_row], matrix[i]
        
        # Eliminate below the pivot
        factor = 1 / matrix[i][i]
        for j in range(n):
            if j != i:
                matrix[j][i] *= factor
        
        # Eliminate above the pivot
        for j in range(i+1, n):
            factor = matrix[j][i]
            for k in range(n):
                matrix[j][k] -= factor * matrix[i][k]
    return matrix

def max_cut(G):
    n = len(G)
    best_cut_value = 0
    for cut in combinations(range(n), n//2):
        cut_value = sum(G[u][v] if (u, v) in G else G[v][u] for u in cut for v in cut if (u, v) not in G and (v, u) not in G)
        best_cut_value = max(best_cut_value, cut_value)
    return best_cut_value

def bonami_beckner_kurtosis(G):
    n = len(G)
    K = 20000
    sum_g_G_x = 0
    sum_g_G_x_squared = 0
    for _ in range(K):
        x = [random.choice([-1, 1]) for _ in range(n)]
        g_G_x = sum(x[i] * G[i][j] if (i, j) in G else x[j] * G[i][j] for i, j in combinations(range(n), 2))
        sum_g_G_x += g_G_x
        sum_g_G_x_squared += g_G_x ** 2
    E_g_G_x = sum_g_G_x / K
    E_g_G_x_squared = sum_g_G_x_squared / K
    return (E_g_G_x**4 / E_g_G_x_squared**2) - 3
