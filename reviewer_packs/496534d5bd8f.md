**Field B** (complexity object): AC^0[MOD_p] circuit structure approximating PARITY (Williams-style ACC^0 lower bounds)

**Statement**:

> Let C be any AC^0[MOD_p] circuit (p an odd prime ≥ 3) of size s and depth d on n inputs that ε-approximates PARITY_n, i.e. Pr_{x∈{0,1}^n}[C(x)=PARITY(x)] ≥ 1/2 + ε. Construct the underlying multigraph G_C by giving each MOD_p gate p parallel edges to each of its inputs, each AND/OR/NOT gate one edge per input, and each circuit input one edge to a common 'sink' node. Then the 2-rank of the sandpile (critical) group K(G_C) = Z^{|V|-1}/imL̃ satisfies rk_2(K(G_C)) ≥ c · ε · n^{1/d} / log(s+1) for an absolute constant c > 0; equivalently, any circuit with sandpile 2-rank below this threshold cannot ε-approximate PARITY.

**Rationale (proposer's reasoning)**:

> Sandpile p-rank is a *syntactic, relational* invariant of the circuit DAG (computed from the Laplacian's Smith normal form, not from the truth table), so it sidesteps Razborov–Rudich naturalness. Smith normal form over Z is fundamentally a torsion/integer-lattice operation, with no clean lift to a polynomial extension of the Boolean ring, so it dodges Aaronson–Wigderson algebrization. The conjecture leverages the known fact that AC^0[MOD_p] is Smolensky-obstructed against PARITY by *modular-algebraic* reasons, and proposes that the obstruction reveals itself as torsion in the spanning-tree module of the circuit's multigraph.
