## 1. Conjecture
**Field A** (mathematical branch): Sum-of-Squares hierarchy pseudo-moment matrices built from Walsh-Hadamard (Fourier-Hankel) signatures
**Field B** (complexity object): ACC0[3] circuit complexity of the depth-2 Sipser function S_n (top OR of bottom ANDs of fan-in ~sqrt(n))

**Statement**:

> For f:{0,1}^n -> {-1,+1}, let B_d = {S subset of [n] : |S| <= d} and let Q_d(f) be the |B_d| x |B_d| symmetric matrix with entries Q_d(f)[S,T] = fhat(S xor T), where fhat(U) = 2^{-n} sum_x f(x) (-1)^{<U,x>}. Define the SoS-Fourier negativity gap NG_d(f) := -lambda_min(Q_d(f)). The conjecture: (i) for every f computable by a depth-3 ACC0[3] circuit of size s, NG_d(f) <= s^{-1/2} for all d <= log s, and (ii) for the explicit Sipser function S_n with bottom fan-in floor(sqrt(n)) and top fan-in ceil(sqrt(n)), NG_2(S_n) >= 1/(8n). A single ACC0[3] circuit (with size up to n*log n, depth 3) achieving NG_2 >= 1/(8n), or a single n in {6,8,10} where Sipser yields NG_2 < 1/(8n), refutes it.

**Rationale (proposer's reasoning)**:

> Q_d(f) is the Gram matrix of the SoS pseudo-expectation E[chi_S * chi_T * f]; its negative-spectrum component encodes obstructions to writing f as a sum-of-squares of degree-d Fourier polynomials. Random and ACC0[3] truth tables have Fourier mass concentrated at low |U|, forcing Q_d to be near-PSD (small NG). Sipser's tight DNF/CNF gap creates a sign-cancellation pattern on medium-sized Fourier coefficients that, viewed through the Hankel skew, should produce a robust negative eigenvalue at degree 2 - and crucially the property 'high negativity' is SMALL (random f gives NG = O(2^{-n/2})), so the property avoids the Razborov-Rudich largeness condition while remaining useful and subexp-computable.

from fractions import Fraction
from itertools import combinations

def fourier_hat(f, U):
    n = len(U)
    return sum(f(x) * (-1)**sum(1 for i in range(n) if x & (1 << i)) / 2**n for x in range(2**n))

def gram_matrix(f, d):
    B_d = list(combinations(range(len(f)), d))
    Q_d = [[0] * len(B_d) for _ in range(len(B_d))]
    for S, T in combinations(B_d, 2):
        Q_d[B_d.index(S)][B_d.index(T)] = fourier_hat(f, S ^ T)
        Q_d[B_d.index(T)][B_d.index(S)] = Q_d[B_d.index(S)][B_d.index(T)]
    Q_d[B_d.index(B_d[0])][B_d.index(B_d[0])] = sum(fourier_hat(f, U)**2 for U in B_d) / len(B_d)
    return Q_d

def eigenvalues(Q_d):
    n = len(Q_d)
    if n == 1:
        return [Q_d[0][0]]
    
    # Gaussian elimination to find the eigenvalues
    A = [[Q_d[i][j] for j in range(n)] for i in range(n)]
    for k in range(n):
        max_row = max(range(k, n), key=lambda i: abs(A[i][k]))
        A[k], A[max_row] = A[max_row], A[k]

            factor = A[j][k] / A[k][k]

    # Extract the eigenvalues from the diagonal
    return [A[i][i] for i in range(n)]
