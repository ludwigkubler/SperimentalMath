# Persistent H1 Lifespan Bounds Resolution Width on Tseitin Formulas

## 1. Conjecture
**Field A** (mathematical branch): Persistent Homology (Topological Data Analysis on filtered simplicial complexes)
**Field B** (complexity object): Resolution proof width of Tseitin formulas

**Statement**:

> For a 3-regular graph G with odd charge, build the Vietoris-Rips filtration on the clause-incidence point cloud P(φ_G) ⊂ R^n (each clause is a ±1 vector on its variables), and let L1(φ_G) be the sum of lifespans (death − birth) of all H1 bars truncated at scale 2√3. Then there exists an absolute constant C ≥ 1 such that the resolution proof width w(φ_G) satisfies w(φ_G) ≤ C · (L1(φ_G) + log n), and equivalently L1(φ_G) = Ω(w(φ_G)) − O(log n). A single 3-regular Tseitin instance with L1(φ_G) < (w(φ_G) − log₂ n)/C for every C ≤ 10 falsifies the conjecture.

**Rationale (proposer's reasoning)**:

> Resolution width on Tseitin formulas is governed by expansion of the underlying graph (Ben-Sasson–Wigderson), and persistent H1 lifespans of the clause point cloud quantitatively detect 1-cycles in the parity constraint hypergraph — exactly the topological feature that forces wide clauses. Persistent homology has been applied to neural net loss landscapes and SAT phase transitions but, to our knowledge, never to Tseitin resolution width as a relational, scale-parametrized invariant (likely <5 papers).  Because the construction is metric-and-combinatorial (Rips filtration on ±1 vectors), it does not algebrize, does not relativize (graph-dependent), and is not a poly-time large+useful property of truth tables, dodging the three textbook barriers and the natural-proofs trap.

def gaussian_elimination(A):
    n = len(A)
    for i in range(n):
        max_row = i
        for j in range(i+1, n):
            if abs(A[j][i]) > abs(A[max_row][i]):
                max_row = j
        A[i], A[max_row] = A[max_row], A[i]
