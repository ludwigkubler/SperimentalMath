> Let f: {0,1}^n × {0,1}^n → {0,1} be a Boolean function with communication matrix M_f. If M_f is K_{s,t}-free (no complete bipartite subgraph K_{s,t}), then the monotone circuit size of f is at least z(n,n,s,t)², where z(n,n,s,t) is the Zarankiewicz number for K_{s,t}-free bipartite graphs.

def generate_kst_free_matrix(n, s, t):

def monotone_circuit_size(matrix):
    n = len(matrix)
