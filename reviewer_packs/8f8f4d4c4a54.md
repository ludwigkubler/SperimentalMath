**Statement**:

> Let C be an AC⁰ depth-d circuit on n inputs with m internal gates g_1,…,g_m (including the output, excluding input literals). Let p_g := Pr_{x~U_n}[g(x)=1] (estimated by N=min(2^n, 2^14) random samples) and define ψ(C) := (1/m)·Σ_g [−log_2(2·max(min(p_g, 1−p_g), 1/(2m)))]. CONJECTURE: (a) ψ(C) ≤ log_2 m + 1 for every AC⁰ circuit C [universal cap]; (b) for every AC⁰ depth-d circuit C exactly computing PARITY_n, ψ(C) ≥ 0.2·n^{1/(d−1)} [PARITY witness]. Combining (a)+(b) yields log_2 size(C) ≥ 0.2·n^{1/(d−1)} − 1.

                a = stack.pop()
                if gate == 'AND':
                    stack.append(a and b)

                    stack.append(a or b)

        p_g = Fraction(count, N)
        return p_g
    
    def psi(C):
        m = len(C)
        total = 0
        for g in C:

            min_p_g = min(p_g, 1 - p_g)
            max_min_p_g = max(min_p_g, Fraction(1, 2 * m))

        return total / m

                circuit.append(term)
