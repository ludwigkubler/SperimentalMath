## Möbius Mass of Gate-Support Meet-Semilattice Bounds AC⁰ PARITY Size

- **Recorded**: 2026-05-08 00:24 UTC
- **Entry ID**: `15f8d5df3519`

### Statement

For an AC⁰ circuit C on n inputs, let P_C be the meet-semilattice generated by the gate variable-supports {S(g) : g ∈ gates(C)} together with ∅ and [n], closed under set intersection and ordered by ⊆, and let μ_{P_C} denote its Möbius function. Define the Möbius-mass invariant ψ(C) := log_2( 1 + Σ_{S ∈ P_C} |μ_{P_C}(∅, S)| ); this is naturally invariant under the S_n action permuting input variables, hence descends to the Sherstov pattern-matrix symmetry group. We conjecture that for every AC⁰ circuit C of depth d that computes PARITY_n exactly, ψ(C) ≥ c · n^{1/(d-1)} for an absolute constant c > 0 independent of d, n; a single counterexample (one PARITY-correct circuit with ψ(C) below this threshold) refutes it.

### Rationale

Random restrictions are blind to the global meet-structure of gate supports, but the Möbius function on the support lattice encodes all higher-order intersection inclusion-exclusion in one rational number — exactly what shellability/Cohen-Macaulay arguments leverage. Because PARITY genuinely depends on all n inputs, any AC⁰ circuit computing it must populate rank-strata of its support meet-semilattice in a way that prevents the alternating sum from collapsing, forcing |μ|-mass to accumulate as the depth tightens the fan-in budget per layer.

## Stern-Brocot Rank of Truth Tables Lifts Average-to-Worst MCSP

- **Verdict**: `BARRIER_HIT`

- **Recorded**: 2026-05-08 00:42 UTC
- **Entry ID**: `7d4339776448`

### Statement

For f: {0,1}^k → {0,1}, encode T(f) as the bigint p_f = Σ_x f(x)·2^{val(x)} ∈ [0, 2^{2^k}) and define the Stern-Brocot rank SB(f) = Σ_j a_j, the sum of partial quotients of the continued-fraction expansion of p_f / 2^{2^k} (equivalently, the depth of p_f/2^{2^k} in the Stern-Brocot tree). We conjecture: (i) for uniformly random f, E[SB(f)] = Θ(2^k · k) with concentration |SB − E[SB]| = O(2^k · k^{1/2}) whp; (ii) every f computed by a Boolean circuit of size s ≤ 2^{k/4} satisfies SB(f) ≤ C · s · 2^{k/2} · k for an absolute constant C; (iii) SB is XOR-additive up to slack: SB(f ⊕ g) ≥ SB(f) + SB(g) − O(k+ℓ), so any worst-case lower bound SB(h) = ω(2^{k/2}·k) on a target h amplifies via t-fold XOR into a 2^{Ω(t)} lower bound on gap-MCSP for the hardness-amplified family — a concrete avg-to-worst transfer.

### Rationale

Sums of continued-fraction partial quotients are arithmetic invariants reflecting the multiplicative structure of the integer p_f, which is exactly the regime in which Yao-XOR composes truth-table integers; truth tables of low-complexity circuits inherit short Euclidean reductions while Gauss–Kuzmin / Hensley statistics force random TTs to have SB ≳ 2^k·k. The k/4 circuit-size threshold sits a polynomial factor below the Razborov–Rudich largeness threshold 2^{k/2}, so the predicted gap can in principle evade natural proofs while still yielding sub-exponential lower bounds. Continued-fraction combinatorics has essentially never been used as a circuit-lower-bound proxy, so the bridge could expose new arithmetic/structural invariants of MCSP-hard truth tables.
