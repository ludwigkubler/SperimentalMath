**Field B** (complexity object): Read-twice branching program (BP) size for IP_2_n = ⊕_{i=1}^n x_i·y_i, in the Borodin–Razborov–Smolensky 1993 model

**Statement**:

> For a layered BP P with state set S of size s and layers k=1..L, let M_k = M_k^{0}+M_k^{1} be the (variable-marginalized) integer transition matrix of layer k, set M̄_k = M_k − (tr M_k / s)·I_s, and let g(P) ⊂ M_s(Q) be the Lie subalgebra generated under [A,B]=AB−BA by {M̄_1,…,M̄_L}. Define the distinguishing tensor ρ(P) := nilpotency class of g(P) (smallest c such that every (c+1)-fold nested commutator of generators is the zero matrix; ρ(P)=∞ if g(P) is not nilpotent). Conjecture: (A) for every read-twice BP P, ρ(P) ≤ 4·log_2(size(P)) + O(1); (B) for the canonical unrestricted product BP for IP_2_n, ρ ≥ ⌈n/2⌉; together (A)+(B) imply any read-twice BP for IP_2_n has size ≥ 2^{Ω(n)}.

**Rationale (proposer's reasoning)**:

> Reading a variable twice forces the same layer matrix to appear at two filtration depths, which should collapse iterated commutators (cap nilpotency class by log-size), whereas the inner-product BP encodes a non-degenerate symplectic form whose product representation interleaves Heisenberg-type commutators of depth Θ(n).
