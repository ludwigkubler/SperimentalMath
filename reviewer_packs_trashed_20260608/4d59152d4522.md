**Statement**:

> For every connected 3-regular graph G on n vertices and odd parity vector σ ∈ {0,1}^V with Σ σ ≡ 1 (mod 2), define ν(G) := n² · Φ_LP(G), where Φ_LP(G) := min { Σ_{(u,v)∈E} d(u,v) : d a semimetric on V with Σ_{u<v} d(u,v) = 1 } is the Leighton-Rao sparsest-cut LP value (a polynomial-size LP). Then there is an absolute constant c > 0 with log_2 L_R(Tseitin(G,σ)) ≥ c · ν(G) for every such (G,σ), and moreover ν(G) ≤ 8 whenever G has tree-width ≤ 3 (so ν is O(1) on every non-expander family).

import random

from collections import defaultdict

def gaussian_elimination(A):
    n = len(A)
    for i in range(n):
        # Find pivot row
        max_row = i
        for j in range(i + 1, n):
            if abs(A[j][i]) > abs(A[max_row][i]):
                max_row = j
        A[i], A[max_row] = A[max_row], A[i]
        
        # Eliminate below pivot
        for j in range(i + 1, n):
            factor = A[j][i] / A[i][i]
            for k in range(n + 1):
                A[j][k] -= factor * A[i][k]
    
    # Back-substitute to get solution
    x = [0] * n
    for i in range(n - 1, -1, -1):
        x[i] = A[i][n] / A[i][i]
        for j in range(i + 1, n):
            x[i] -= A[i][j] * x[j]
    
    return x

def solve_linear_system(A, b):

            edges.add((u, v))
    return list(edges)

        else:

        clauses.append([neg_literals[v], literals[u]])

def dpll(clauses):
