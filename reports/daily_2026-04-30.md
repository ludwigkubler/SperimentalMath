## Tropical Derivation Sparsity Limits Phase Cell Count

- **Verdict**: `INCONCLUSIVE`

- **Recorded**: 2026-04-30 07:04 UTC
- **Entry ID**: `f7d5775dddc6`

### Statement

For any tropical circuit C computing a function provably total in IΔ₀, the number of phase cells in its circuit phase space is bounded above by a polynomial in the sparsity of its tropical derivation δ(C), where sparsity is the maximum number of non-zero entries in the active edge structure across all inputs.

### Rationale

This conjecture tests Axiom A1 (Phase Stability Axiom) by linking phase cell complexity — a geometric proxy for proof complexity — to the combinatorial sparsity of the tropical derivation. In IΔ₀, functions have limited induction strength, so their tropicalizations should not induce exponentially many phase transitions. If true, this would imply that functions with sparse derivation maps cannot generate complex phase geometries, reinforcing the idea that IΔ₀ corresponds to low phase complexity in TCWA.

## VC-Dimension of Row-Induced Set System Bounds Monotone DNF Size for k-CLIQUE

- **Verdict**: `INCONCLUSIVE`
- **Bridge**: Statistical learning theory (VC-theory) × Monotone DNF representation size
- **Recorded**: 2026-04-30 10:09 UTC
- **Entry ID**: `91f293427310`

### Statement

Let F be a monotone DNF formula representing the k-CLIQUE function on n-vertex graphs. Let S_F be the set system induced by the truth-table rows of F, where each row corresponds to a graph and each term in F defines a set of graphs containing that term's edges. Then the VC-dimension of S_F is at least Ω(n) and any such DNF with VC-dimension v satisfies |F| ≥ 2^{v/4}.

Monotone DNFs with few terms can only shatter small sets of variables, limiting their VC-dimension. The k-CLIQUE function requires distinguishing all k-subsets, which induces a large shattering, potentially exposing an information-theoretic bottleneck in compact representation.
