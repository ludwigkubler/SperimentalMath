**Field B** (complexity object): Read-twice oblivious branching program size for IP_2 on 2n variables in adversarial order x_1,...,x_n,y_1,...,y_n (Borodin-Razborov-Smolensky 1993 open separation)

**Statement**:

> Let P be a read-twice oblivious BP with state set Q (|Q|=s) computing a Boolean function on N=2n variables, and let q(z,ℓ) denote its state on input z after ℓ steps. For each state q∈Q and each layer ℓ∈{1,...,2N}, define the centered conditional moment sequence m^{q,ℓ}_k(P) = 2^{-N} Σ_z 𝟙[q(z,ℓ)=q]·(IP_2(z)-1/2)^k for k=0,...,⌊N/4⌋, and let H^{q,ℓ}(P) be the (d+1)×(d+1) Hankel matrix with d=⌊N/8⌋ and entries m^{q,ℓ}_{i+j}. Define the positivity defect δ(P) = max_{q,ℓ} #{negative eigenvalues of H^{q,ℓ}(P)}. Conjecture: (i) for every read-twice oblivious BP P of size s, δ(P) ≤ 8·⌈log_2(s+1)⌉; (ii) every read-twice oblivious BP P that exactly computes IP_2 in the adversarial schedule satisfies δ(P) ≥ ⌈√N/2⌉.

**Rationale (proposer's reasoning)**:

> Curto-Fialkow theory equates degree-2d SoS feasibility with the existence of flat positive extensions of truncated Hankel sequences, so a small BP forces low-rank flat extensions of its layer-conditional empirical moments — a structural constraint never previously exploited for BP lower bounds. IP_2's bilinear ⊕-structure should force every conditional sub-population reaching a given state at a given layer to retain non-trivial bilinear correlation between the unread x-bits and the moments, obstructing flat positive Hankel extension and producing many negative eigenvalues. The conjectured gap log(s) vs √N would yield s ≥ 2^{Ω(√N)} for read-twice IP_2, attacking the BRS-1993 problem via the SoS-moment side rather than via communication or partition arguments.
