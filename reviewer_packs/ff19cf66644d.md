**Field B** (complexity object): Resolution refutation length L_R(Tseitin(G,σ)) of 3-regular Tseitin formulas with odd vertex charge σ (the Urquhart / Ben-Sasson–Wigderson canonical sub-Frege target)

**Statement**:

> Let G be a connected 3-regular graph on n vertices and m=3n/2 edges, and let σ∈F_2^V have odd total parity. Define the cut-threshold indicator f_G:{0,1}^V→{0,1} by f_G(x)=1 iff |E(S_x,V\S_x)|≤m/3, where S_x={v:x_v=1}, and let its level-≤k Fourier mass be W_{≤k}[f_G]=Σ_{|S|≤k} f̂_G(S)^2. Define ν(G):=−log_2 W_{≤⌊n/8⌋}[f_G]−log_2(1/E[f_G]+1). The conjecture: log_2 L_R(Tseitin(G,σ))≥c·ν(G) for an absolute constant c≥1/12, while ν(G)=O(1) whenever G admits a vertex separator of size O(1) with O(1) edge boundary; a single 3-regular instance on n≤40 violating log_2 L_R≥(1/12)·ν(G) refutes the bound.

**Rationale (proposer's reasoning)**:

> On expander G, cuts are sharply concentrated near m/2 by Bonami–Beckner hypercontractivity applied to the (n-junta) cut function, so f_G is a near-zero, low-influence boolean function and its low-degree mass W_{≤n/8} is exponentially small, forcing ν(G)=Ω(n) and matching the Urquhart 2^{Ω(n)} resolution lower bound. On non-expanders the small-cut event is realized by a constant-size junta of separator vertices, so f_G is essentially a low-degree function and W_{≤n/8} is Ω(1), driving ν(G)=O(1). This bridges the Friedgut–Bourgain low-degree-mass / junta machinery (rarely applied to proof complexity) directly to Tseitin resolution via the cut indicator, without invoking spectral λ_2 or vertex expansion explicitly.

        while any(d != 3 for d in degrees):
            u, v = random.sample(range(n), 2)
            if u not in G[v] and v not in G[u]:
                G[u].append(v)
                G[v].append(u)
                degrees[u] += 1
                degrees[v] += 1
        return G

        # Two K3,3 blocks joined by a small bridge
        G = [[] for _ in range(6)]

        G[3], G[4], G[5] = [0, 5], [0, 4], [1, 4]
        return G

        # Cycle of K4 gadgets

            G[4 * i + 3] = [4 * i, 4 * (i + 1) % (4 * n)]

    def walsh_hadamard_transform(f):
        n = len(f)
        for s in range(1, n):
            mask = 1 << s
            for i in range(n // (2 ** s)):
                for j in range(2 ** s):
                    f[i * (2 ** s) + j] += f[i * (2 ** s) + j + mask]
        return f
