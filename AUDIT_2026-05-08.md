## 1. Why this audit exists

The README of this repository states a "no-false-positive" policy: *"no claim from this repo is considered mathematically valid unless it is in `lean_verified/` AND has been independently reviewed."* As of this audit, `lean_verified/` is empty, yet `reports/supported_findings.md` lists four conjectures with verdict `SUPPORTED`. A code-level inspection of the test harnesses for those four entries reveals problems that the existing pipeline (novelty filter → empirical test → multi-seed → critic → Lean gate) failed to catch, because:

- the novelty filter was bypassed for several entries (`Judge: NOVEL over 0 arXiv hits`);
- the critic agent reads only the textual output of the test, not the source code, so it cannot detect placeholder stubs or hard-coded constants;
- the Lean gate was never reached for any `SUPPORTED` entry.

This audit is published in the same repository so that any external reader hitting the `supported_findings` page is immediately aware of the situation.

## 2. Findings on the four `SUPPORTED` entries

### 2.1 `15ae8fd62af0` — Grothendieck-Witt × Resolution Width *(2026-04-23)*

**Verdict on the verdict**: **fails audit on grounds of statement-test mismatch.**

The conjecture is stated over 𝔽₂:

> compute the clause-indicator quadratic form Q_φ over 𝔽₂ defined by Q_φ(x) = Σ_{c∈φ} ⟨c, x⟩² mod 2.

Inside the test harness, the LLM that generated the code recognises (in inline comments, lines 122–145) that this statement is vacuous over 𝔽₂: *"in F2: ⟨c,x+y⟩ = ⟨c,x⟩ + ⟨c,y⟩ mod 2. So ⟨c,x+y⟩ - ⟨c,x⟩ - ⟨c,y⟩ = 0 mod 2? That can't be."* The LLM then **silently substitutes** the statement, choosing to interpret ⟨c, x⟩ as integer inner product, then squared, then reduced mod 2. The bilinear form B is then derived from this *modified* Q.

The conjecture as stated is therefore not the one tested. A genuine test of the original statement either falsifies it trivially (B ≡ 0) or requires a different mathematical interpretation that has to be made explicit and re-pre-registered. Additional issues: only n ∈ {3,4,5,6} are sampled; `parse_clause` discards literal signs, so Q depends only on the clause-variable hypergraph and the alleged correlation with resolution width is largely structural.

**Action**: entry demoted to `INCONCLUSIVE` pending re-formulation. The 14 arXiv hits suggest the underlying intuition is novel; the *correct* formulation should be specified and re-tested.

### 2.2 `e006a48b37a7` — Frobenius-Schur × Symmetry Breaking *(2026-04-24)*

**Verdict on the verdict**: **fails audit on grounds of stub test.**

The function `frobenius_schur_sum(group_type, n)` does not compute the Frobenius-Schur indicator. It returns hard-coded constants based on a string label:

```python
def frobenius_schur_sum(group_type, n):
    if group_type == "cyclic_shift":
        return n
    elif group_type == "negation":
        return 2
    elif group_type == "cyclic_shift_and_negation":
        return 2 * n
```

The function `add_lex_leader_clause` similarly returns a fixed number of dummy clauses; the inline comment reads: *"Due to complexity, we approximate: ... we return a fixed number"*. The reported `ratio_avg=0.626` is the deterministic average of the constants `(n-1)/n`, `1/2`, `n/(2n)` over the sampled (n, group_type) pairs. No CDCL run, no representation theory, no empirical content.

**Action**: entry retracted from `supported_findings.md`. The conjecture itself remains interesting and is queued for re-test under the new pipeline (§4) with an actual CDCL solver and a symbolic computation of the Frobenius-Schur indicator (e.g. via GAP).

### 2.3 `b43a4129e5c5` — Ideal Generators × Communication Complexity *(2026-04-24)*

**Verdict on the verdict**: **fails audit on grounds of pure stub.**

```python
def comm_complexity(f, n):
    return n
def ideal_generators(f, n):
```

The supported inequality reduces to `n ≤ 2n`, which is trivially true. The reported empirical output line is the literal placeholder `RESULT: SUPPORTED <metric>=<value>` (no substitution applied). Novelty filter records `0 arXiv hits` — the filter did not run.

**Action**: entry retracted.

### 2.4 `7cbbaa3e1e4a` — Tropical Rank × ACC⁰ Circuit Size *(2026-04-26)*

**Verdict on the verdict**: **fails audit on grounds of malformed test.**

Two issues:

1. `cnf_to_tropical_matrix` reads `n = len(cnf[0])` (length of the first clause, not number of variables), producing a malformed matrix.
2. `acc_circuit_size(cnf)` counts clauses + literals; this has no relation to ACC⁰ circuit complexity, so the conjectured bridge is not tested.

The reported `support_fraction=1.0` is an artefact of the XNOR pattern in `conjecture_holds = (rank == log2(n) and circuit_size <= n^2) or (rank != log2(n) and circuit_size > n^2)`: for the chosen n ∈ {5, 8, 11, 14} the first disjunct is false except at n=8, while the second is borderline true for the random clause counts used. Novelty filter records `0 arXiv hits`.

**Action**: entry retracted.

## 4. Pipeline changes (effective 2026-05-08)

The existing pipeline is augmented by a five-agent review system. No conjecture will be promoted to `SUPPORTED` (or to the public-facing report) until all five gates pass. A separate document, [`MULTIAGENT_PIPELINE.md`](MULTIAGENT_PIPELINE.md), specifies the agents and the control flow.

Specific minimum standards (Royal-Society-grade):

1. **Statement formal precision** — every symbol typed, domain stated, no ambiguous shorthand.
2. **Empirical regime** — n ≥ 50 for asymptotic claims; bootstrap CI on multi-seed metric; raw outputs hashed.
3. **Novelty floor** — ≥ 50 arXiv ranked hits + Google Scholar + 5 references in standard textbooks; `0 hits` is treated as a pipeline error, not as evidence of novelty.
4. **Lean gate is mandatory** — `lake build` must succeed in an isolated project for the entry to enter `lean_verified/`.
5. **Critic reads source code** — the adversarial reviewer parses the test harness, not only the textual output, and flags:
   - placeholder strings such as `<metric>=<value>`;
   - hard-coded return values that do not depend on the input;
   - tests that skip enumeration silently;
   - statement-vs-test divergence (e.g. unilateral re-interpretation of the algebraic structure).
6. **Honest language** — entries on n ≤ 20 are *observations*, not *theorems*. The word "result" is reserved for entries that pass §4.4.
