**Statement**:

> For an unsat 3-CNF F on n variables with m clauses, construct a braid word β(F) ∈ B_n by reading clauses C ∈ F in lex order: for each C with literals l_1, l_2, l_3 sorted by |var|, append generators σ_{|l_1|}^{sgn(l_1)·sgn(l_2)} · σ_{|l_2|}^{sgn(l_2)·sgn(l_3)} (σ_k for exponent +1, σ_k^{-1} for exponent −1, with σ_k acting between strands k and k+1, k ≤ n−1; pairs that straddle strand n−1 are skipped). Let M(F) = ρ_{-1}(β(F)) be the unreduced Burau matrix product specialised at t = −1 (so each generator is an integer n × n matrix with entries in {−1, 0, 1, 2}), and ω(F) := |n − tr(M(F))|. Conjecture: there is an absolute constant C ≥ 1/4 such that the canonical lex-DPLL refutation backtrack count t(F) satisfies 4·(t(F)^2 + 1) ≥ ω(F) for every unsat 3-CNF F. A single unsat F with 4·(t(F)^2 + 1) < ω(F) falsifies the conjecture.
