- **Recorded**: 2026-05-16 20:13 UTC
- **Entry ID**: `0e06b5f9fc52`

### Statement

Let P be a read-twice branching program with state set S (|S|=s) on n Boolean variables. For each of the 2n read-positions r ∈ {1,…,2n} let A_r ∈ R^{s×s} be the averaged transition matrix A_r := (T_r^0 + T_r^1)/2, where T_r^b is the 0/1 matrix sending state u to state v if reading bit b at position r drives u→v. ## Mobius-Mertens Cancellation on Fourier Levels vs Total Influence

### Statement
