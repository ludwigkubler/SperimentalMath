## 1. Conjecture
**Field A** (mathematical branch): Real algebraic geometry: Hermite-Vandermonde discriminant of a real-rooted characteristic polynomial and Fekete-Szego logarithmic capacity on the real line
**Field B** (complexity object): Degree-2 SOS (Goemans-Williamson / Delorme-Poljak) spectral upper bound for max-CUT, viewed as a moment-matrix invariant relevant to algebraic proof systems related to Extended Frege

**Statement**:

> For a graph G on n vertices with adjacency eigenvalues lambda_1 <= ... <= lambda_n, define LogDisc(G) := (1/n^2) * sum_{i<j} log|lambda_i - lambda_j| (the normalized Hermite-Vandermonde log-discriminant of the real-rooted characteristic polynomial det(tI - A)) and define the degree-2 SOS spectral slack S(G) := (|E|/2 - (n/4)*lambda_1 - MaxCut(G))/n. Conjecture: over independent uniformly random 3-regular graphs at each fixed n in {12,16,20}, the Pearson correlation rho(S, LogDisc) satisfies rho >= 0.4, and there exist universal constants a in (0,5), b in R such that |E[S] - a*E[LogDisc] - b| <= 0.05 for all such n. A single random instance with S(G) > 0.2 while LogDisc(G) <= -1 falsifies the conjecture.

**Rationale (proposer's reasoning)**:

> The Delorme-Poljak spectral bound for max-CUT is tight precisely when the adjacency spectrum is concentrated near its extreme eigenvalue, whereas the Hermite-Vandermonde log-discriminant is the real-algebraic obstruction to root coalescence (Fekete-Szego logarithmic energy on the real line). Linking the SOS spectral slack to a classical RAG invariant of the characteristic polynomial sidesteps ring-extension arithmetization (so it should evade algebrization) and avoids any single-truth-table predicate (so it should evade natural proofs). The invariant is relational (compares pairs of eigenvalues), not a single-number truth-table statistic.

def run_trial(seed: int) -> dict:

    def generate_3regular_graph(n):
        while True:
            edges = set()
            for i in range(n):
                neighbors = random.sample(range(n), 2)
                if (i, neighbors[0]) not in edges and (neighbors[0], i) not in edges:
                    edges.add((i, neighbors[0]))
                    edges.add((i, neighbors[1]))
            if len(edges) == n * 3 // 2:
                return [set() for _ in range(n)], list(edges)
    
    def adjacency_matrix_to_eigenvalues(A):
        n = len(A)
        eigenvalues = []
        for i in range(100):  # Max 100 iterations to avoid infinite loop
            v = [random.gauss(0, 1) for _ in range(n)]
            v /= math.sqrt(sum(x * x for x in v))
            Av = [sum(A[i][j] * v[j] for j in range(n)) for i in range(n)]
            lambda_i = sum(v[i] * Av[i] for i in range(n)) / sum(v[i] * v[i] for i in range(n))
            eigenvalues.append(lambda_i)
        return sorted(eigenvalues)
    
    def max_cut(G):
        n = len(G)
        best_cut_size = 0
        for mask in range(1 << n):
            cut_size = sum((mask >> i) & 1 for i in range(n))
            if cut_size > best_cut_size:
                left = [i for i in range(n) if (mask >> i) & 1]
                right = [i for i in range(n) if not (mask >> i) & 1]
                cut_size = sum(1 for u, v in G if ((u in left and v in right) or (v in left and u in right)))
                best_cut_size = cut_size
        return best_cut_size
    
    def log_disc(eigenvalues):
        n = len(eigenvalues)
        total = 0
        for i in range(n):
            for j in range(i + 1, n):
                gap = abs(eigenvalues[i] - eigenvalues[j])
                if gap > 1e-12:
                    total += math.log(gap)
        return total / (n * n)
    
    def ols_regression(x, y):
        n = len(x)
        sum_x = sum(x)
        sum_y = sum(y)
        sum_xy = sum(xi * yi for xi, yi in zip(x, y))
        sum_xx = sum(xi * xi for xi in x)
        a = (n * sum_xy - sum_x * sum_y) / (n * sum_xx - sum_x ** 2)
        b = (sum_y - a * sum_x) / n
        return a, b
    
    def pearson_correlation(x, y):
        n = len(x)
        mean_x = sum(x) / n
        mean_y = sum(y) / n
        cov_xy = sum((xi - mean_x) * (yi - mean_y) for xi, yi in zip(x, y)) / n
        std_x = math.sqrt(sum((xi - mean_x) ** 2 for xi in x) / n)
        std_y = math.sqrt(sum((yi - mean_y) ** 2 for yi in y) / n)
        return cov_xy / (std_x * std_y)

            "n": n,
            "log_disc": log_disc_value,
            "max_cut": max_cut_value,
            "sos_slack": (len(edges) / 2 - (n / 4) * eigenvalues[0] - max_cut_value) / n
