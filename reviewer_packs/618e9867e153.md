**Statement**:

> Let M∈{±1}^{N×N} have singular values σ_1≥…≥σ_N≥0; since ‖M‖_F^2=N^2 the weights p_i:=σ_i^2/N^2 form a probability distribution on [N]. Define the empirical descending-cumulative CDF F_M:[0,1]→[0,1] by F_M(t):=Σ_{i≤⌊tN⌋} p_i and the Halász L^2 discrepancy against the uniform-spectrum reference U(t)=t by D_2(M):=(∫_0^1 (F_M(t)−t)^2 dt)^{1/2}∈[0,1/√3]. Conjecture: there exists an absolute constant c>0 such that for every M∈{±1}^{N×N}, σ_{⌊N/2⌋+1}(M)^2 ≥ c·N·(1−4·D_2(M))_+ (where (x)_+:=max(0,x)); a single sign matrix exhibiting σ_{⌊N/2⌋+1}^2 < (c/2)·N·(1−4D_2)_+ falsifies it.

**Rationale (proposer's reasoning)**:

> Halász-type L^2 discrepancy measures how concentrated the squared spectrum is relative to the entropy-maximizing flat profile; a flat (low-discrepancy) spectrum forces σ_{N/2+1} to remain Θ(√N), the canonical Friedman regime where the rigidity lower bound is tight. The bridge encodes the heuristic that 'spectral-uniformity ⇒ rigidity', upgraded to a quantitative discrepancy-to-Friedman bound, and the use of integration plus absolute values blocks any polynomial-extension lift that would trigger algebrization. Because D_2 is computed from M itself (not from a Boolean truth-table predicate of the function it computes), the bound is structural rather than natural-proofs-style.
