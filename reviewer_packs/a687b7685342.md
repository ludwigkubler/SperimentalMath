**Statement**:

> For a 3-regular graph G=(V,E) and odd charge σ:V→F_2, define the augmented Forman-Ricci curvature on edge e=(u,v) by F(e) := 2·t(e) + 2·q(e) − (deg(u)+deg(v)−2), where t(e) is the number of triangles through e and q(e) is the number of induced 4-cycles through e. Let N_−(G) := #{e ∈ E : F(e) < 0}. We conjecture absolute constants c ≥ 0.4 and C ≤ 5 such that log_2 T_DPLL(Tseitin(G,σ)) ≥ c · N_−(G) − C for every odd-charged 3-regular Tseitin instance with |V| ≥ 12, where T_DPLL counts recursive calls under unit propagation and a fixed lex variable order; one instance with log_2 T_DPLL < c·N_−(G) − C falsifies it.

**Rationale (proposer's reasoning)**:

> Negative Forman-Ricci on an edge encodes local 'tree-like' branching geometry — neither triangles nor short squares can short-circuit width-building inferences across e — so the count N_−(G) is a poly-time, S_n-natural proxy for the 'expander mass' that powers Ben-Sasson–Wigderson width lower bounds, but read off from purely local edge statistics rather than λ_2 or Cheeger flow. Because Forman curvature decouples cleanly from spectral and metric-embedding invariants already attempted on Tseitin (Laplacian gap, Ollivier-Ricci, Ihara zeta, Leighton-Rao), an empirical correlation would expose a new local-to-global handle on the Urquhart target. The bridge is barrier-safe: the invariant is graph-only (no truth-table access), so no natural-proofs largeness, and it relativizes/algebrizes trivially.
