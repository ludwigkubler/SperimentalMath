# Mealy Automaticity Lower-Bounds Truth-Table Formula Size

## 1. Conjecture
**Field A** (mathematical branch): Finite-state transducer minimization / 2-automaticity of binary sequences (Allouche–Shallit automaticity over the alphabet {0,1}, distinct from any compression-based complexity)
**Field B** (complexity object): Meta-complexity: minimum {AND,OR,NOT}-formula leaf count L(f) of a truth table, used as a tractable MCSP proxy

**Statement**:

> For an n-variable Boolean function f with truth table T_f ∈ {0,1}^{2^n}, let A(f) be the number of states of the minimum complete DFA over alphabet {0,1} that accepts L_f = { bin_n(k) : T_f[k] = 1 }, where bin_n(k) is the n-bit MSB-first binary expansion of k. Let L(f) be the leaf-count of the smallest {AND,OR,NOT}-formula computing f over the literals x_1,…,x_n,¬x_1,…,¬x_n. Conjecture: for every n ≥ 2 and every f, A(f) ≤ (n+2)·L(f) + 2; equivalently, log_2 A(f) ≤ log_2 L(f) + log_2(n+2) + o(1). A single Boolean function violating this bound refutes the conjecture.

**Rationale (proposer's reasoning)**:

> Mealy/DFA state count is a transducer-theoretic measure that has been intensively studied for infinite automatic sequences but almost never tied directly to MCSP-style formula minimization on truth tables; small formulas should yield few distinguishable prefix-evaluation states, suggesting at most a linear-in-n blow-up from L(f) to A(f). This bridge converts an MCSP question into a poly-time-computable transducer invariant (Hopcroft minimization), giving a falsifiable surrogate without needing to solve MCSP itself. If the bound fails, the offending function exposes a 'state-rich, formula-cheap' object — a new natural property candidate that would not relativize, fitting the META_COMPLEXITY safe-direction profile.
