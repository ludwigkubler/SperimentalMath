**Field B** (complexity object): Communication complexity

**Statement**:

> For any 3-CNF formula with n variables, the Fourier entropy (sum of squared coefficients) of its characteristic function is Θ(log n) if and only if the communication complexity of the function's equality problem is Θ(n).

**Rationale (proposer's reasoning)**:

> Fourier entropy captures the distribution of influence across variables, while communication complexity measures the minimal information exchange needed. Their inverse relationship suggests that functions with concentrated Fourier entropy (low entropy) require more communication, aligning with known bounds in communication complexity.

def run_trial(seed: int) -> dict:

            var = random.randint(1, n)
            sign = random.choice([-1, 1])
            if random.random() < 0.5:
                clauses.append((var, sign))
            else:
                clauses.append((-var, -sign))
        return clauses
    
    def fourier_entropy(n, clauses):
        total = 0
        for subset in range(2**n):
            prob = 1
            for i in range(n):
                if (subset >> i) & 1:
                    sign = sum(clause[1] for clause in clauses if clause[0] == i + 1)
                    prob *= math.exp(-sign * 1j * math.pi / n)
                else:
                    sign = sum(clause[1] for clause in clauses if clause[0] == -i - 1)
                    prob *= math.exp(sign * 1j * math.pi / n)
            total += abs(prob) ** 2
        return total

        return n
