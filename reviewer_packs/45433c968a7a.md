**Statement**:

> For a connected graph G=(V,E) with |V|=n, |E|=m, let f_G(x_e)=Σ_{spanning tree T}∏_{e∈T}x_e be its multilinear spanning-tree polynomial; f_G is Lorentzian, so its Hessian H_G∈R^{m×m} at x=1, whose entries are H_G[e,e']=τ_{e,e'} for e≠e' and 0 on the diagonal, has signature (+,−,−,…,−) with a unique positive eigenvalue λ_1(H_G)>0 and remaining eigenvalues λ_2≥…≥λ_m all ≤0. Define the Lorentzian Hessian gap g(G):=λ_1(H_G)−λ_2(H_G)≥λ_1(H_G)>0 (normalized by τ(G) so that off-diagonal entries equal P(e,e'∈T)). CONJECTURE: there exists an absolute constant c>0 such that for every connected G with n≥6 and m≥n, the Delorme–Poljak SOS-2 upper bound DP(G):=m/2+(n/4)|λ_min(A_G)| exceeds the true MaxCut by at least DP(G)−MaxCut(G) ≥ c·g(G)·n; a single graph G violating this for the empirically calibrated c falsifies the conjecture.

**Rationale (proposer's reasoning)**:

> The Lorentzian Hessian encodes the global negative-correlation structure of edges in a uniform random spanning tree (Burton–Pemantle), an instance-level matroid-Hodge invariant orthogonal to the cut-spectral structure that SOS-2 exploits; a large gap g(G) signals matroid-balanced 'spread' that we predict the eigenvalue/SDP relaxation cannot reproduce, forcing slack against true MaxCut. def determinant(matrix):

        return matrix[0][0]
    det = 0

        sub_det = determinant(submatrix)
        det += sign * matrix[0][c] * sub_det
