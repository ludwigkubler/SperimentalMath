**Field B** (complexity object): Monotone Boolean functions (random k-uniform monotone DNFs under lattice ∧/∨)

**Statement**:

> For a monotone DNF F = ∨_i T_i on N variables, build the term-overlap graph H(F): vertices are the minimal terms of F (after deleting terms strictly dominated by others), and an edge {T_i, T_j} is present iff T_i ∩ T_j ≠ ∅. Define the mean unweighted Forman-Ricci curvature μ(F) := (1/|E(H)|) Σ_{e=uv ∈ E(H)} (4 − deg(u) − deg(v) + 3·tri(uv)), where tri(uv) counts triangles through e, with the convention μ(F) := 0 when H(F) has no edges. Conjecture (SC3 step): for every pair of monotone DNFs F, G on N ≤ 40 variables, each having at most 20 terms of size k = ⌈log₂ N⌉, the lattice submodularity defect Δ(F,G) := μ(F ∧ G) + μ(F ∨ G) − μ(F) − μ(G) satisfies |Δ(F,G)| ≤ 4·√N; a single (F,G) with |Δ| > 4·√N refutes.

**Rationale (proposer's reasoning)**:

> Forman-Ricci curvature is a discrete Bochner-type invariant whose averaged value on dense random graphs concentrates around a linear function of the average degree, and lattice operations on monotone DNFs translate cleanly into union/dominance operations on term-overlap hypergraphs. Standard discrete-Bochner heuristics predict approximate submodularity (Δ ≤ 0) with bounded slack on random ensembles, but the operation F ∧ G squares the number of raw terms before dominance reduction, so a √N slack is a quantitatively non-trivial prediction. Either confirming a √N envelope, or producing a single linear-in-N violation, settles whether μ behaves like a lattice-Bochner functional in the SC3 regime.

import math

def run_trial(seed: int) -> dict:

    def generate_dnf(N, k):
        return set(random.sample(range(1, N+1), k) for _ in range(20))
    
    def reduce_dnf(dnf):
        dnf = list(dnf)
        n = len(dnf)
        while True:
            changed = False
            for i in range(n-1):
                for j in range(i+1, n):
                    if dnf[i].issubset(dnf[j]):
                        del dnf[j]
                        n -= 1
                        changed = True
                    elif dnf[j].issubset(dnf[i]):
                        del dnf[i]
                        n -= 1
                        changed = True
            if not changed:
                break
        return set(dnf)
    
    def compute_overlap_graph(dnf):
        terms = list(dnf)
        n = len(terms)
        A = [[0] * n for _ in range(n)]
        for i in range(n):
            for j in range(i+1, n):
                if terms[i].intersection(terms[j]):
                    A[i][j] = 1
                    A[j][i] = 1
        return A
    
    def compute_forman_ricci_curvature(A):
        n = len(A)
        deg = [sum(row) for row in A]
        tri = [[0] * n for _ in range(n)]
        for i in range(n):
            for j in range(i+1, n):
                if A[i][j]:
                    for k in range(j+1, n):
                        if A[i][k] and A[j][k]:
                            tri[i][j] += 1
        mu = sum(4 - deg[i] - deg[j] + 3 * tri[i][j] for i in range(n) for j in range(i+1, n)) / (n * (n-1))
        return mu
    
    def compute_lattice_submodularity_defect(F, G):

        F_or_G = reduce_dnf(F.intersection(G))

        mu_F_or_G = compute_forman_ricci_curvature(compute_overlap_graph(F_or_G))
        mu_F = compute_forman_ricci_curvature(compute_overlap_graph(F))
        mu_G = compute_forman_ricci_curvature(compute_overlap_graph(G))
        return abs(mu_F_and_G + mu_F_or_G - mu_F - mu_G)
