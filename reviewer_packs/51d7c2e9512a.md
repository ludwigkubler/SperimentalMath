# Restriction-Local Fourier Doubling Gap for ACC[2] vs Sipser

## 1. Conjecture
**Field A** (mathematical branch): Additive combinatorics: Plünnecke-Ruzsa doubling of heavy Fourier supports in F_2^k
**Field B** (complexity object): ACC[2] circuits and the depth-d Sipser function (worst-case lower bound via average over restrictions)

**Statement**:

> For f:{0,1}^n→{±1} and a random restriction ρ that zeros a uniformly random (n−k)-subset of inputs and keeps k=⌈log_2 n⌉ alive, let f|ρ be the resulting k-variable function with Walsh-Hadamard spectrum ĝ. Define HF(g)={S⊆[k]:|ĝ(S)|≥1/4} and Doub(f)=E_ρ[|HF(f|ρ)ΔHF(f|ρ)|/max(1,|HF(f|ρ)|)]. Conjecture: (i) every AC⁰[⊕] (a.k.a. ACC[2]) circuit C of size s and depth d satisfies Doub(f_C) ≤ (1+log s)^{2d}; (ii) the depth-3 Sipser function S_n with alternating fan-ins ≈n^{1/3} satisfies Doub(S_n) ≥ √(log n)/6 for all n≥16. A single (n,seed) instance violating either bound refutes the conjecture.

**Rationale (proposer's reasoning)**:

> Razborov-Smolensky says ACC[2] functions are approximated by low-degree F_2-polynomials, whose Fourier mass is concentrated on a low-weight, additively-structured (Freiman-like) family of characters; restricting to a log-sized window preserves this structure, so the heavy support inherits small doubling. Sipser's recursive AND-OR-AND amplifier instead spreads heavy Fourier mass across characters with no F_2-affine structure, so restriction averaging exposes a doubling gap. The construction escapes natural proofs by being non-large: random f has empty HF after restriction (so Doub=0), meaning random functions trivially satisfy the ACC[2] bound — the property does not distinguish random from easy, only Sipser from easy.

def run_trial(seed: int) -> dict:

    def evaluate_circuit(circuit, input):
        stack = []
        for gate in circuit:
            if gate == 'AND':
                a = stack.pop()
                b = stack.pop()
                stack.append(a and b)
            elif gate == 'OR':
                a = stack.pop()
                b = stack.pop()
                stack.append(a or b)
            elif gate == '⊕':
                a = stack.pop()
                b = stack.pop()
                stack.append(a != b)

                stack.append(gate(input))
        return stack[0]
    
    def walsh_hadamard_transform(f, n):
        N = 2**n
        result = [0] * N
        for i in range(N):
            for j in range(N):
                result[i] += f(j) * (-1)**(i & j)
        return [x / math.sqrt(N) for x in result]
    
    def hamming_weight(x):
        return bin(x).count('1')
    
    def freiman_family_size(k, n):
        return 2**(n - k + 1)
    
    def doubling(g, tau=0.25):
        N = len(g)
        HF = [g[i] for i in range(N) if abs(g[i]) >= tau]
        return sum(abs(HF[i] - HF[j]) for i in range(len(HF)) for j in range(i+1, len(HF))) / max(1, len(HF))
    
    def generate_random_circuit(n):
