**Field B** (complexity object): Randomized two-party communication complexity of AND-functions M_g(x∧y) on {0,1}^n × {0,1}^n, with the prototype g = AND-of-NOTs giving M = M_DISJ_n (Razborov 1992 Ω(n) regime). **Statement**:

> For g: {0,1}^n → {0,1}, let M_g ∈ {0,1}^{2^n × 2^n} be the AND-function communication matrix M_g[x,y] = g(x ∧ y). With σ_i = singular values of M_g, define τ(M_g) := log_2((Σ_i σ_i)^2 / (Σ_i σ_i^4)^{1/2}) = 2·log_2(||M_g||_{S_1}) − log_2(||M_g||_{S_4}^2). Conjecture (A): for every AND-function, CC_R^{1/3}(M_g) ≥ (1/8) τ(M_g) − 2; (B): for M_DISJ_n (g(z) = ∏_i(1−z_i)), τ(M_DISJ_n) = n·log_2(5/√7) ≈ 0.918n, exactly. A single AND-function M_g with τ(M_g) > 8·D^cc(M_g) + 16, or any n with τ(M_DISJ_n) < 0.7n, falsifies.

**Rationale (proposer's reasoning)**:

> The DISJ matrix factors as a tensor power of the 2×2 block (1,1;1,0) with golden-ratio spectrum {φ, −1/φ}, so its Schatten norms have closed forms (||·||_{S_p}^p = (φ^p + φ^{−p})^n), giving τ = Θ(n) by exact computation rather than spectral inequalities. The (S_1, S_4) ratio strengthens Forster's (S_2, S_∞) ratio: it is more sensitive to mid-spectrum mass while remaining sub-multiplicative under tensor product, the same algebraic property that makes Tseitin-on-expanders amenable to width-via-expansion arguments. If proved, conjecture (A) yields a clean, calculable tensor invariant that matches Razborov's Ω(n) bound on a wide AND-function class and would import noncommutative L^p techniques into proof-complexity-flavored CC lower bounds.
