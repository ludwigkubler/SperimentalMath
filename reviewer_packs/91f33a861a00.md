**Statement**:

> For every unsatisfiable 3-CNF Φ on n variables with m clauses, define f_Φ:{0,1}^n→[0,1] by f_Φ(x)=(1/m)·#{C∈Φ : x⊨C}, let g_Φ := f_Φ − E_x[f_Φ], and define the hypercontractive flatness exponent E(Φ) := ‖g_Φ‖_4^4 / ‖g_Φ‖_2^4 (with conventions E=1 when g_Φ≡0; by Cauchy–Schwarz E≥1). We conjecture log_2 T_DPLL(Φ) ≥ (n − log_2 m) / E(Φ) − 5 for every such Φ; a single instance violating this bound falsifies the conjecture.

**Rationale (proposer's reasoning)**:

> Bonami–Beckner hypercontractivity tells us that small E(g)=‖g‖_4^4/‖g‖_2^4 forces the Walsh spectrum of g to be 'flat' (close to white noise), so a flat clause-count function lacks the low-degree structure that DPLL's unit propagation can exploit — predicting near-2^n search trees — while a peaked spectrum (large E) signals a low-degree certificate that DPLL can find quickly. def gaussian_elimination(A, b):
