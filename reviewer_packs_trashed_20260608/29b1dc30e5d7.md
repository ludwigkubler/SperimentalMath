## 1. Conjecture
**Field A** (mathematical branch): Hyperplane arrangement theory (Orlik-Solomon / Zaslavsky region counting via Möbius function of the intersection lattice)
**Field B** (complexity object): ACC^0[m] circuit size for CNF-represented Boolean functions

**Statement**:

> For a CNF formula F on n variables with clauses C_1,...,C_k, build the rational hyperplane arrangement A_F = {H_{C_j}} where H_C = {x ∈ Q^n : Σ_{i∈P_C} x_i − Σ_{i∈N_C} x_i = |P_C| − 1} (P_C, N_C are positive/negative literal indices). Let r(A_F) = Σ_{X ∈ L(A_F)} |μ(0̂,X)| be the Zaslavsky region count, equal to (−1)^n χ(A_F,−1). CONJECTURE: if the Boolean function defined by F is computable by an ACC^0[m] circuit of depth d and size s, then log_2 r(A_F) ≤ c · d · (log_2 s + log_2 n) for an absolute constant c ≤ 4; one CNF whose function has a small ACC^0[m] circuit but exhibits log r(A_F) > 4d(log s + log n) refutes it.

**Rationale (proposer's reasoning)**:

> Williams' ACC^0 program exploits that ACC^0-computable functions yield low-complexity algebraic shadows (sparse multilinear polynomials, low-rank factor matrices); the supported tropical-rank result confirmed clause-indicator polynomials carry an ACC-sensitive invariant. The Möbius/region invariant of the dual hyperplane arrangement is a different yet equally elementary algebraic shadow, never (to my knowledge) tied to ACC^0, and it is preserved under the structural reductions Williams uses. It evades relativization (defined on the syntactic CNF, not via oracle access) and natural-proofs largeness (random CNFs typically yield exponentially larger r, so the property is non-large on the ACC^0 side).

def mat_rank(rows, ncols):
    """Return rank of matrix (list of list of Fraction)."""
    M = [r[:] for r in rows]
    pivot_row = 0
    for col in range(ncols):
        found = -1
        for r in range(pivot_row, len(M)):
            if M[r][col] != 0:
                found = r
                break

def clause_to_row(clause, n):

    clause: list of signed ints (1-indexed); positive = positive literal,

    Row: [a_1,...,a_n, rhs]  stored as Fractions.

def zaslavsky_region_count(clauses, n):

    linearly-independent generators up to augmented rank), then do Möbius
    inversion to get sum |mu|.

    basis) rather than just rank.

def cnf_parity(n):
    """XOR of all n variables as CNF (2^(n-1) clauses)."""
    clauses = []
    for assignment in itertools.product([-1, 1], repeat=n):
        if assignment.count(-1) % 2 == 0:
            clause = [i + 1 if assignment[i] == 1 else -(i + 1) for i in range(n)]
            clauses.append(clause)
    return clauses

def cnf_mod3(n):
    """(sum of vars) mod 3 == 0 as CNF."""
    clauses = []
    for assignment in itertools.product([0, 1], repeat=n):
        if sum(assignment) % 3 != 0:
            clause = [-(i + 1) if assignment[i] == 1 else (i + 1) for i in range(n)]
            clauses.append(clause)
    return clauses

def cnf_and_mod2(n):
    """(x1 AND x2 AND x3) XOR (x4 XOR ... XOR xn) as CNF (approx)."""
    half = n // 2
    clauses = []
    # AND part: x1 AND ... AND x_half, i.e. single clause enforcing all=1
    # XOR part on remaining vars
    for assignment in itertools.product([0, 1], repeat=n):
        and_part = all(assignment[i] == 1 for i in range(half))
        xor_part = sum(assignment[half:]) % 2
        result = int(and_part) ^ xor_part
        if result != 1:
            clause = [-(i + 1) if assignment[i] == 1 else (i + 1) for i in range(n)]
            clauses.append(clause)
    return clauses
