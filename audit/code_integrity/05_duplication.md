## 4. Suggested refactors

Five concrete extractions, prioritized by impact:

1. **`sandbox_archive/` test-file prelude (C01, C02 — ~2,900 file pairs)** —
   every `test_*.py` in `~/Scrivania/SEC/research/git_mirrors/SperimentalMath/sandbox_archive/`
   starts with an identical 14-line stdlib import block (`itertools`, `collections`, `json`, …)
   followed by a typing/fractions block. Extract to
   `~/Scrivania/SEC/research/git_mirrors/SperimentalMath/sandbox_archive/_prelude.py`
   and have the test harness inject `from _prelude import *`, or stop emitting the
   prelude in the test-generator. Eliminates ~18 KLOC of pure boilerplate.

2. **`pvsnp_explorer.py` duplicate (C04 — 10,100 tok, ~1,440 LOC)** —
   `~/Scrivania/SEC/src/research/pvsnp_explorer.py` and
   `~/kissat/pvnp_lab/system_v2/src/pvsnp_explorer.py` are near-identical full files.
   Pick one canonical location (`pvnp_lab/system_v2/src/` per project_sec_server_paths
   memory) and have the other import from it, or replace with a symlink. Same fix for
   C15 (`pvsnp_monitor.py`), C17 (`pvsnp_report.py`), C20 (`pvsnp_framework.py`).

3. **`math_practice_*` / `math_proof_*` test scaffolding (C03, C07 — ~200 files)** —
   per-problem test scripts under `~/Scrivania/future/practice/` and `~/projects/practice/`
   share 120-220 tokens of setup. Refactor the generator to emit a single
   `_test_harness.py` and per-problem `case_<id>.py` data file. Saves ~5 KLOC.

4. **Combinatorial helper functions (C11, C14, C16, C19 — ~600 files)** —
   small math utilities (`gcd`, `lcm`, `is_prime`, `divisors`, factorial loops)
   are re-inlined per test. Extract to
   `~/Scrivania/SEC/research/git_mirrors/SperimentalMath/sandbox_archive/_mathlib.py`
   and import. Saves ~5-7 KLOC, also fixes correctness drift between copies.

5. **SEC <-> kissat/pvnp_lab cross-tree duplication (C04, C15, C17, C20)** —
   four research modules exist in two trees (`Scrivania/SEC/src/research/` and
   `kissat/pvnp_lab/system_v2/src/`). Per the `project_sec_server_paths` memory the
   canonical SEC path is on server only — make `kissat/pvnp_lab/system_v2/src/` the
   single source of truth and delete the SEC mirrors (or vice-versa). ~3,000 LOC removed,
   eliminates divergence risk.
