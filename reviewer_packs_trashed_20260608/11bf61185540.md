**Statement**:

> For any 2-party Boolean function f: {0,1}^n x {0,1}^n -> {0,1}, define the signed weight-profile 3-tensor S_f in R^{(n+1) x (n+1) x (n+1)} by S_f[i,j,k] := (1/Z_{i,j,k}) * sum_{|a|=i, |b|=j, |a cap b|=k} (-1)^{f(a,b)}, where Z_{i,j,k} = binom(n,i)*binom(i,k)*binom(n-i,j-k) is the orbit size (so S_f is a sign-mean per (i,j,k) cell, with S_f=0 if Z=0). Let kappa(f) := rank over Q of the mode-1 unfolding of S_f after thresholding singular values at 1/(n+1)^2. Conjecture (C): for every f, R_{1/3}^{cc}(f) >= (1/8) * kappa(f) * log(n) - O(log n); in particular kappa(DISJ_n) = Theta(n) (saturating the (n+1) bound) while kappa(EQ_n), kappa(GT_n with Alice<Bob trivialized), and kappa of any f with R^{cc}(f) = O(log n) are O(log n). One counterexample = one function with measurable R^{cc} <= c log(n) but kappa >= 2c log(n) + 4 falsifies (C).

**Rationale (proposer's reasoning)**:

> The S_n x S_n-orbit-averaged tensor S_f is the natural symmetric-group projector seen by any communication protocol whose acceptance probability is exchangeable in the indices (which all known DISJ protocols essentially are, by Razborov's symmetrization). Apolarity says the unfolding rank of S_f counts the apolar Hilbert function of the polarized form sum f(a,b) x^a y^b, an invariant of the underlying secant geometry on the Segre P^n x P^n. The conjecture predicts that this apolar defect is exactly what forces high randomized cost on DISJ while collapsing on permutation-invariant low-communication functions like EQ.

        result *= (n - i + 1)
        result //= i
