# Dual-VC Dimension of KW Conflict Family Bounds Formula Depth
**Entry ID**: `4b8d8bea6f73`  **Verdict**: `INCONCLUSIVE`  **Recorded**: 2026-05-19 18:40:03 UTC

## 1. Conjecture
**Field A** (mathematical branch): Vapnik-Chervonenkis dimension theory (Sauer-Shelah dual shatter function)
**Field B** (complexity object): Karchmer-Wigderson game / de Morgan formula depth

**Statement**:

> Let f:{0,1}^n->{0,1} be non-constant and define the Karchmer-Wigderson conflict family L_f = { D(x,y) : x in f^{-1}(1), y in f^{-1}(0) } over ground set [n], where D(x,y) = { i in [n] : x_i != y_i }. Let dvc(f) be the dual VC dimension of L_f: the largest k such that some k-subset T of [n] is shattered by L_f, i.e., every U⊆T equals A∩T for some A in L_f. CONJECTURE: for every non-constant f on n>=4, the minimum de Morgan formula depth satisfies d(f) >= ceil(log2(dvc(f)+1)); equivalently, dvc(f) <= 2^{d(f)} - 1. A single triple (f, dvc(f), d(f)) with d(f) < ceil(log2(dvc(f)+1)) falsifies it.

**Rationale (proposer's reasoning)**:

> A depth-d KW protocol partitions f^{-1}(1) x f^{-1}(0) into at most 2^d rectangles each pinned to a coordinate that must occur in every conflict set within the rectangle, so L_f's projection patterns on any fixed coordinate set T are constrained by a coverage of at most 2^d 'leaf stars', bounding the achievable shattered cardinality. Dual VC dimension is a *relational* invariant of the bipartite KW structure (not a truth-table single number), and it fails to exclude ACC0 (XOR is in AC0[2] yet has dvc = n-1), so it is not 'useful' in the Razborov-Rudich sense and dodges the natural-proofs trap while still giving a genuine depth lower bound. Sauer-Shelah duality is essentially unused in KW analyses — under five hits on arXiv linking VC-shatter to Karchmer-Wigderson protocols.
