## 5. TOML / YAML

### 5.1 TOML (20 random sampled)

7 parse failures — all `Cargo.toml` files in `Scrivania/future/...` directories. Root cause: the files start with a markdown code fence:

```
```toml
[package]
...
```

i.e. the file is a *markdown-fenced* TOML, not raw TOML. These were emitted as documentation/snippets, not as compilable Rust manifests. They will silently break `cargo build`.

Real `lakefile.toml` files (mathlib deps, kissat lean projects), `pyproject.toml`, and properly-formed `Cargo.toml` files all parsed cleanly.
