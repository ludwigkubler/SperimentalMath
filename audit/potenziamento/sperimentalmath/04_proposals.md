## P1 — Retraction propagator (HIGHEST PRIORITY)

- **Titolo**: `apply_retractions.py` — single-pass propagator from `retractions.json` → all reports.
- **Descrizione**: a script that reads `retractions.json` and, for each `entry_id`, (a) deletes the entry from `reports/supported_findings.md` / `reports/falsified_findings.md` and inserts a `## RETRACTED — <title> (entry_id)` stub with the reason; (b) appends a `"retracted": true` field to the corresponding `notebook/2026-*.jsonl` row; (c) prepends a banner to the reviewer pack PDF generator stub: `[RETRACTED 2026-05-08 — see AUDIT_2026-05-08.md §<n>]`.
- **Motivazione + URL**: Retraction Watch and OSF policy — retraction is not deletion, it is *annotation* on the same DOI/URL. https://retractionwatch.com/ ; https://cajmhe.com/index.php/journal/article/view/401
- **File to create**: `~/Scrivania/SEC/research/git_mirrors/SperimentalMath/scripts/apply_retractions.py` (new). Hook it into `sync_output.sh` between the report regeneration and the `git commit` step.
- **Primo test**: run on current `retractions.json` (9 entries). Verify `supported_findings.md` ends with **zero** un-retracted entries (because all 4 are retracted/demoted), and 6 FALSIFIED are stamped RETRACTED.
- **Ore-uomo**: 4-6 h.

## P2 — AST-based source auditor (Gate 1 enforcement)

- **Titolo**: `gate1_auditor.py` — automated stub-and-placeholder detector.
- **Descrizione**: Python script using `ast` to walk each test harness in `sandbox_archive/` and flag: (1) functions whose `return` is a constant-folded expression independent of every argument (caught 3 of the 4 SUPPORTED retractions); (2) string literals containing `<metric>`, `<value>`, `???`; (3) `print` / stdout output containing `skipping`, `Too many ... configurations`, `falling back to dummy`; (4) test wall-clock < 0.05 s when claiming ≥ 200 instances. Output JSON written to `audit/gate1_<entry_id>.json`. Test harness rejected if any red flag.
- **Motivazione + URL**: spec already exists in `MULTIAGENT_PIPELINE.md §3.1` but is not running (health report: `skeptic_168h.not_invoked = 405`). Mathlib4 CI lint policy is the model: nothing merges without lint. https://leanprover-community.github.io/contribute/index.html
- **File**: new `scripts/gate1_auditor.py`. Wire into `pvnp_lab/system_v2` cycle after the test phase.
- **Primo test**: run retroactively on the 4 retracted SUPPORTED entries. Expectation: all 4 flagged (3 by rule 1, 1 by rule 4 / wall-clock).
- **Ore-uomo**: 8-12 h.
