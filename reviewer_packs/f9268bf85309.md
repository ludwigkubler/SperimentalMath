# Slice Rank of Layer-Variable Tensor Lower-Bounds Read-Twice BP Size for IP_2

## 1. Conjecture
**Field A** (mathematical branch): Slice rank / partition rank in additive combinatorics (Croot-Lev-Pach 2016, Tao 2016, Naslund 2020)
**Field B** (complexity object): Read-twice branching programs computing IP_2 = ⊕_i x_i·y_i (Borodin–Razborov–Smolensky 1993 read-twice barrier)

**Statement**:

> For a read-k branching program P with vertex set V(P), define the layer-variable tensor T_P ∈ F_2^{|V|×|V|×n} by T_P[u,v,j] := (number of edges u→v labelled by a literal of x_j) mod 2, and let ρ(P) := slice_rank_{F_2}(T_P). Conjecture (A) For every read-twice branching program P, ρ(P) ≤ 6·log_2 |V(P)|. Conjecture (B) For every (unrestricted) branching program P that computes IP_2 on n variables, ρ(P) ≥ n/8; in particular any read-twice P for IP_2 satisfies |V(P)| ≥ 2^{n/48}, and a single (P,ρ) pair refuting either inequality falsifies the claim.

**Rationale (proposer's reasoning)**:

> Slice rank is the F_2 invariant that drove the cap-set collapse: it measures how far a 3-tensor is from being decomposable along axis-aligned slabs, and read-twice forces the variable axis of T_P to be a sparse, low-multiplicity fiber pattern — exactly the regime where Tao-style slice arguments give logarithmic bounds. Conversely, IP_2 is the canonical bilinear obstruction, and any BP encoding it must spread the x_j-fibers of T_P across many slices because each x_j actually multiplies a distinct y_j, conjecturally producing a partition-rank-style anti-cap configuration with linear slice rank. The bridge is novel because slice rank has been deployed for cap sets, sunflower bounds, and matrix multiplication exponent, but never (to <5 papers) as a BP-size lower-bound invariant.
