**Statement**:

> For a connected graph G on n vertices with Laplacian L_G having nontrivial eigenvalues 0 < λ_2 ≤ … ≤ λ_n, let σ̃(G) = {λ_2/λ_n, …, λ_{n-1}/λ_n, 1} be the spectrum rescaled into (0,1], and define the normalized Fekete capacity Cap(G) := (∏_{2 ≤ i<j ≤ n} |λ̃_i − λ̃_j|)^{2/((n−1)(n−2))} ∈ [0,1] (the transfinite diameter of the rescaled spectrum, taken as 0 when any pair coincides exactly). A single graph G with gap(G) > C · Cap(G) by additive margin > 0.01 refutes the conjecture.
