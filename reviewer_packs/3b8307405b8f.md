## 1. Conjecture
**Field A** (mathematical branch): Discrete Morse theory and cellular homology of 2-CW complexes (Forman 1998; Benedetti–Lutz)
**Field B** (complexity object): Resolution refutations of the Pigeonhole Principle PHP_{n+1→n} as a sub-system of Frege/Extended Frege

**Statement**:

> Given any resolution refutation P of PHP_{n+1→n}, define its triangle 2-CW complex K(P): 0-cells are the distinct clauses occurring in P, 1-cells are unordered pairs {C,D} of clauses that co-appear as inputs/output of at least one resolution step, and 2-cells are triangular faces {A,B,R} for each resolution inference A,B ⊢ R. Let β_1(K(P);F_2) = (|E| − |V| + β_0) − rank_{F_2}(∂_2) be the first mod-2 Betti number. Conjecture: for every n ≥ 3 and every (tree-like or DAG) resolution refutation P of PHP_{n+1→n}, β_1(K(P);F_2) ≥ ⌊n · log_2(n+1)⌋, and moreover the ratio β_1(K(P))/|P| stabilizes to a strictly positive constant c_PHP > 0 as n grows; a single instance with β_1 < ⌊n·log_2(n+1)⌋ refutes the conjecture.

**Rationale (proposer's reasoning)**:

> Resolution proofs are routinely measured by size/width but almost never by the cellular topology of the inference DAG itself; treating each resolution rule as a glued triangle yields a 2-complex whose homology is a functorial invariant of the proof object, not of the encoded truth-table — sidestepping the Razborov-Rudich natural-proofs trap that killed prior single-number truth-table attempts in this approach. The construction is purely combinatorial (no arithmetization, no oracle), so it does not algebrize or relativize. If β_1 genuinely scales with n it provides a Frege-relevant complexity lower bound complementing Haken's width method while exposing a previously unmeasured topological resource.

    def gaussian_elimination(matrix):

            max_row = i + max(range(i, rows), key=lambda r: abs(matrix[r][i]))
            matrix[i], matrix[max_row] = matrix[max_row], matrix[i]

                if j != i:

                    for k in range(rows):
                        matrix[j][k] -= factor * matrix[i][k]
        rank = sum(1 for row in matrix if any(row))
        return rank
    
    def compute_beta_1(vertices, edges, triangles):
        V, E, F = len(vertices), len(edges), len(triangles)
        beta_0 = 1
        boundary_matrix = [[0] * (E + F) for _ in range(E)]
        for i, (C, D) in enumerate(edges):
            boundary_matrix[i][i] = -1
            boundary_matrix[i][i + E] = 1
        for j, (A, B) in enumerate(triangles):
            boundary_matrix[j + E][j] = -1
            boundary_matrix[j + E][j + F] = 1
        rank_boundary = gaussian_elimination(boundary_matrix)
        return (E - V + beta_0) - rank_boundary
    
    def dpll(clauses, assignment):
