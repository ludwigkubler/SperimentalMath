## 1. Conjecture
**Field A** (mathematical branch): Fourier analysis of boolean functions (total influence / Poincaré inequality)
**Field B** (complexity object): DPLL search tree leaf count on random 3-CNF

**Statement**:

> For a 3-CNF F on n variables, define g_F:{-1,1}^n -> {-1,1} as the parity (XOR) of the clause-indicators c_i(x)=OR(literals_i)(x), i.e. g_F(x)=prod_i (2*c_i(x)-1). Let I[g_F] = sum_S |hat{g_F}(S)|^2 |S| be the total influence computed exactly via the 2^n-point Fourier transform of g_F. The conjecture asserts that for every 3-CNF F with n<=20, the number L(F) of leaves of the standard DPLL tree (unit-propagation + pure-literal + lex variable order) satisfies L(F) <= 2^{I[g_F] + log2(n+1)}, and conversely L(F) >= 2^{I[g_F]/3 - 1}; one violating instance refutes either bound.

**Rationale (proposer's reasoning)**:

> Total influence controls how 'unstructured' a boolean function is — low-influence functions are juntas (Friedgut) and high-influence ones spread mass over large coordinate subsets, which intuitively should govern how many branching paths a lex DPLL must explore. Encoding F as the XOR of its clause indicators creates a single ±1 function whose Fourier spectrum is computable in O(n·2^n) and ties together global clause structure rather than treating clauses independently. A two-sided bound is falsifier-friendly and forces the influence to track DPLL branching tightly, sharpening the Kahn–Kalai–Linial intuition on a non-monotone, formula-derived function.

        if n == 1:
            return f

        odd = walsh_hadamard_transform([f[i] for i in range(1, len(f), 2)], n // 2)
        result = [0] * n

            result[k] = even[k] + odd[k]
            result[k + n // 2] = even[k] - odd[k]
        return result

        f_hat = walsh_hadamard_transform(f, n)

            f_hat[k] /= math.sqrt(n)
        return f_hat
    
    def g_F(x, clauses):
        return sum(2 * any(lit == x[i] for i, lit in enumerate(clause)) - 1 for clause in clauses) % 2
    
    def dpll(F, assignment, literals):

            return True
