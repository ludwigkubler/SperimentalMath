# Layer-Commutator Frobenius Discrepancy Separates Read-Twice BP for IP_2

## 1. Conjecture
**Field A** (mathematical branch): Non-commutative operator discrepancy (Frobenius norm of layer-transition commutators, viewed as a Σ^b_1-witnessing measure in bounded arithmetic à la Cook–Krajíček)
**Field B** (complexity object): Read-twice branching programs computing the inner-product-mod-2 function IP_2

**Statement**:

> Let P be a read-twice branching program with state set S (|S|=s) on n Boolean variables. For each of the 2n read-positions r ∈ {1,…,2n} let A_r ∈ R^{s×s} be the averaged transition matrix A_r := (T_r^0 + T_r^1)/2, where T_r^b is the 0/1 matrix sending state u to state v if reading bit b at position r drives u→v. Define the layer-commutator Frobenius discrepancy ρ(P) := log_2( 1 + Σ_{1≤r<q≤2n} ‖A_r A_q − A_q A_r‖_F^2 / s^2 ). Conjecture: (a) ρ(P) ≤ 6·log_2(s) + 4 for every read-twice BP P; (b) for every read-twice BP P that computes IP_2 on n ≥ 4 inputs, ρ(P) ≥ (1/8)·n. A single P violating either inequality refutes the conjecture; together they would force size(P) ≥ 2^{n/48} for read-twice BPs computing IP_2.

**Rationale (proposer's reasoning)**:

> Bounded-arithmetic witnessing of BP membership relies on local invariants that are Σ^b_1-definable from the BP layer data; commutator energies of averaged layer matrices are exactly that kind of computable witness, while operator non-commutativity is the algebraic signature of the bilinear structure IP_2(x,y)=⟨x,y⟩_2. Read-once BPs decompose into block-triangular layers where averaged transitions essentially commute on each reachable mass, but IP_2 forces every read-twice realization to mix x-reads and y-reads non-trivially. Because ρ is a Frobenius (L^2 spectral) quantity rather than a polynomial in the entries, the construction does not algebrize and the invariant is computed on BP structure (not the truth table), so it dodges Natural Proofs.

    """Multiply two matrices A and B."""
    if not A or not B:
        return []

    cols_A = len(A[0]) if rows_A > 0 else 0
    rows_B = len(B)
    cols_B = len(B[0]) if rows_B > 0 else 0
