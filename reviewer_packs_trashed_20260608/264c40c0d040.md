**Statement**:

> Let f_n = ⊕-tree_n be the balanced binary tree of XOR gates on n = 2^k inputs, with KW-metric space (X_{f_n}, d_{f_n}). Define the coboundary δ : C^0_coarse(X_{f_n}) -> C^1_coarse(X_{f_n}) and the propagation-R Roe subalgebra C_u^*[X_{f_n}]_R. Then there exists a universal constant α ∈ (0,1) such that, for all R ≤ α·log_2 n, every coarse 1-cocycle c with propagation ≤ R is a coboundary (so its class in HX^1 is trivial), while for R ≥ k = log_2 n there exist nontrivial classes c whose Roe-trace pairing satisfies log|⟨c,T⟩| / log(propagation(T)) ≥ k − O(1). Consequently κ(f_n) ≥ log_2 n − O(1), matching depth(f_n) = Θ(log n) up to constants and certifying axiom A1 sharply for an explicit recursive function.

**Rationale (proposer's reasoning)**:

> This conjecture directly tests axiom A1 (Coarse-KW link) together with A5 (Roe-index rigidity) on the canonical recursive function whose formula depth is exactly known (depth(⊕-tree_n) = log_2 n). Verifying both the vanishing below the threshold and the nonvanishing above gives a sharp quantitative version of A1 on a function whose depth we can independently certify, providing a sanity check that κ is neither overshooting nor undershooting the true formula depth in a controlled recursive setting.

def hamming_distance(x, y):
    return sum(xi != yi for xi, yi in zip(x, y))

def bfs_diameter(tree, root):
    queue = [(root, 0)]
    visited = set([root])
    max_dist = 0
    while queue:
        node, dist = queue.pop(0)
        max_dist = max(max_dist, dist)
        for neighbor in range(len(tree)):
            if tree[node] ^ tree[neighbor] == 1 and neighbor not in visited:
                visited.add(neighbor)
                queue.append((neighbor, dist + 1))
    return max_dist

def build_cochain_space(tree, R):
    n = len(tree)
