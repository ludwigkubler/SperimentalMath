**Statement**:

> Let T(G,b) be an unsatisfiable Tseitin formula on a connected d-regular graph G (d≥3) with parity charges b∈{0,1}^V, and let A(G,b) be the signed adjacency matrix with A_{ij}=(-1)^{b_i+b_j} if {i,j}∈E and 0 otherwise. Form the (n+1)×(n+1) canonical degree-2 SOS moment matrix M(G,b) by setting M_{0,0}=1, M_{0,i}=0, M_{i,i}=1, and M_{i,j}=A_{ij}/(d-1) for i,j≥1; define the spectral Mahler measure m(M)=Σ_{i:|λ_i|>1} log|λ_i| over eigenvalues of M. Conjecture: for every (d,2√(d-1))-spectral expander G and every parity-violating b (Σ b_v ≡ 1 mod 2), m(M(G,b)) ≥ α_d · n − O(log n) with α_d = (1/2)·log((d-1)/(d-2)) > 0, and any degree-2 pseudoexpectation certifying a (0.878+ε)-approximation to Max-CUT on G must have m(M) strictly below α_d·n/2, so its existence is forbidden whenever the conjecture holds.

**Rationale (proposer's reasoning)**:

> Tseitin lower bounds against algebraic relaxations are typically proved via spectral expansion of an associated matrix, but spectral norm alone discards the multiplicative information encoded in the full eigenvalue sequence; the Mahler measure m(M)=log∏max(1,|λ_i|) is precisely the multiplicative invariant from Diophantine geometry (Lehmer's problem, height theory) that aggregates this information. Linking this height-theoretic invariant to SOS feasibility on Tseitin Max-CUT bridges a number-theoretic field essentially absent from proof complexity (≪5 prior papers) with the canonical SOS-vs-Tseitin separation question. Because m(M) is a local function of the spectrum it neither algebrizes (it is not preserved under oracle relativization of M) nor falls to natural proofs (it is a property of the SOS object, not of a Boolean function family).

import random
import math

def generate_random_graph(n, d):
    while True:
        edges = set()
        for i in range(n):
            neighbors = random.sample(range(n), d-1)
            if (i, *neighbors) not in edges and (i, *neighbors[::-1]) not in edges:
                edges.add((i, *neighbors))
        if len(edges) == n * d // 2:
            return [[(j in neighbors) for j in range(n)] for _, *neighbors in edges]

def generate_parity_charges(n):
    return [random.randint(0, 1) for _ in range(n)]

def sign_matrix(A, b):
    n = len(b)
    M = [[0] * (n + 1) for _ in range(n + 1)]
    M[0][0] = 1
    for i in range(n):
        M[i+1][i+1] = 1
        for j in range(i+1, n):
            if A[i][j]:
                M[i+1][j+1] = (-1) ** (b[i] + b[j])
                M[j+1][i+1] = M[i+1][j+1]
    return M

def eigenvalues(matrix):
    def gaussian_elimination(A, B):
        n = len(A)
        for i in range(n):
            max_row = i
            for j in range(i + 1, n):
                if abs(A[j][i]) > abs(A[max_row][i]):
                    max_row = j
            A[i], A[max_row] = A[max_row], A[i]
            B[i], B[max_row] = B[max_row], B[i]
            for j in range(i + 1, n):
                factor = A[j][i] / A[i][i]
                for k in range(i, n):
                    A[j][k] -= factor * A[i][k]
                B[j] -= factor * B[i]
        X = [0] * n
        for i in range(n - 1, -1, -1):
            X[i] = (B[i] - sum(A[i][j] * X[j] for j in range(i + 1, n))) / A[i][i]
        return X

    n = len(matrix)
    A = [[matrix[i][j] if i != j else 0 for j in range(n)] for i in range(n)]
    B = [sum(matrix[i][j] * matrix[j][k] for j in range(n)) for k in range(n)]
    eigenvals = []
    for _ in range(n):
        eigval, A, B = gaussian_elimination(A, B)
        eigenvals.append(eigval)
    return eigenvals

def spectral_mahler_measure(eigenvals):
