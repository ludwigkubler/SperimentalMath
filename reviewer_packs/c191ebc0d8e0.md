**Statement**:

> For a given 3-SAT instance φ, let K_0(φ) denote the Grothendieck group of the category of finite-dimensional representations of the clause-variable incidence graph of φ. Then, the rank of K_0(φ) is bounded above by the resolution width of φ. Moreover, there exists a constant c such that for all φ, rank(K_0(φ)) ≤ c * w(φ), where w(φ) is the resolution width of φ.

**Rationale (proposer's reasoning)**:

> Algebraic K-theory provides a framework for studying the algebraic and geometric properties of categories. In the context of SAT, the incidence graph of a 3-SAT instance can be viewed as a categorical object. The Grothendieck group K_0(φ) encodes information about the representation theory of this graph, which may be related to the resolution width of φ. This conjecture proposes a quantitative relationship between these two objects.

from networkx import Graph, DiGraph
from sage.all import MatrixSpace, QQ, ZZ

def run_trial(seed: int) -> dict:
    random.seed(seed)
    
    def generate_3sat_instance(n):
        clauses = []
        for _ in range(n):
            clause = [random.choice([-1, 1]) * random.randint(1, n) for _ in range(3)]
            clauses.append(clause)
        return clauses

    def incidence_graph(clauses):
        G = DiGraph()
        for i, clause in enumerate(clauses):
            for var in clause:
                if var not in G:
                    G.add_node(var)
                G.add_edge(i, abs(var))
        return G

    def grothendieck_group(G):
        nodes = list(G.nodes())
        M = MatrixSpace(QQ, len(nodes), len(nodes))()
        for u, v in G.edges():
            M[u-1, v-1] += 1
            M[v-1, u-1] -= 1
        return M.echelon_form().rank()

    def resolution_width(clauses):
        width = 0
        stack = []
        for clause in clauses:
            new_clause = [abs(var) for var in clause if var not in stack]
            if len(new_clause) > width:
                width = len(new_clause)
            stack.extend([var for var in clause if var not in stack])
        return width

    n_values = [5, 8, 11, 14]
    results = []

        clauses = generate_3sat_instance(n)
        G = incidence_graph(clauses)

        w_phi = resolution_width(clauses)
        results.append({"n": n, "rank_K0": rank_K0, "w_phi": w_phi})

    max_rank_K0 = max(result["rank_K0"] for result in results)
