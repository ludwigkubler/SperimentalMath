**Field B** (complexity object): Monotone DNF representation size

**Statement**:

> Let F be a monotone DNF formula representing the k-CLIQUE function on n-vertex graphs. Let S_F be the set system induced by the truth-table rows of F, where each row corresponds to a graph and each term in F defines a set of graphs containing that term's edges. Then the VC-dimension of S_F is at least Ω(n) and any such DNF with VC-dimension v satisfies |F| ≥ 2^{v/4}.

**Rationale (proposer's reasoning)**:

> VC-dimension captures the expressive capacity of set systems and is tightly linked to sample complexity in learning theory. Monotone DNFs with few terms can only shatter small sets of variables, limiting their VC-dimension. The k-CLIQUE function requires distinguishing all k-subsets, which induces a large shattering, potentially exposing an information-theoretic bottleneck in compact representation.
